# AK.skill

Choose the smallest module set for the public technical artifact the user requested.
Reuse the supplied topic, audience and format; ask only when the missing choice
changes the work. Read `doc/narrative-core.md` for pack-level mission questions.

| Task need | Load |
|---|---|
| Explain an evidenced workflow or abstraction shift | `paradigm-surface` |
| Support a capability claim with a reproducible artifact | `proof-in-miniature` |
| Express ambition with its actual limits and verification | `hype-discipline-pairing` |
| Turn a useful pattern into an agent-readable specification | `idea-file-handoff` |
| Teach through a small runnable implementation | `irreducible-core` |
| Design bounded experiments around a fixed evaluator | `scoreboard-loop` |
| Explain a stack's change over a specified period | `stack-year-review` |

For a post or thread, a useful order is evidenced shift → proof → limits, adding
an idea file only when requested or useful. Teaching, optimization and annual
reviews start with their own module. Load only applicable modules; a narrow edit
may need one. Do not invent a paradigm shift, lived experience, benchmark or public
hosting requirement to fit the pack. Deliver the requested artifact, not a report
about every module. Canonical source: https://github.com/ERerGB/AK.skill.
